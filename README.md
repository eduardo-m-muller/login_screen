🔐 Tela de Login

Uma tela de login simples, limpa e responsiva, pronta para ser integrada ao seu projeto.

✨ Funcionalidades
- Formulário de login com usuário e senha (pode ser substituido ou embutido com email;
- Mensagens de erro claras (credenciais inválidas, campos vazios);
- Opção de mostrar/ocultar senha;

🛠️ Tecnologias
- Linguagem principal: html5 e JavaScript>
- Estilização: CSS

🚀 Instalação

  # 1. Clone o repositório:
  
    git clone https://github.com/eduardo-m-muller/login-screen.git
  
  # 2. Entre na pasta:
  
    cd login-screen

  # ▶️ Como executar:
  
    clique duas vezes sobre o arquivo html ou baixe a extensão live server no vs code, clique com o 
    botão direito sobre o arquivo html e clique em "open with live server".
